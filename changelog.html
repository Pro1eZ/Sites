Updated October 2026 · Build 1215

Every TrailRig update, newest first. The app is built by one developer and updated frequently — this is the full story.

2.25.x 2.24.x Earlier

Version 2.25

2.25.16 (build 1215) New

  • What's New sheet: after an update, the app now shows a one-time summary of what changed — just like WhatsApp. Dismiss it with Continue, and it won't appear again until the next update.
  • Full release history now published at trailrig.app/changelog.html.

2.25.15 (build 1214)

  • Fixed: Stem "Mount Type" picker label was shown as "Type" — renamed to "Mount Type".
  • Fixed: Searching for stem parts now includes the mount type (Standard / Direct Mount) in the search query.

2.25.14 (build 1213) New

  • Stem component now has a Mount Type field: choose between Standard and Direct Mount.

2.25.13 (build 1212)

  • Fixed: Light component form showed a literal placeholder string instead of "Front Light" / "Rear Light" as the section header.
  • Fixed: Restoring a backup with bikes that had an "Owned since" date set would not reschedule their birthday reminders — they now reschedule correctly on restore.
  • Fixed: Binning a bike on one device via iCloud sync did not cancel the birthday notification on other devices.
  • Fixed: Decrementing a cassette cog stepper back to 0 left a stale auto-filled range string (e.g. "10-51t") — range is now cleared when either cog is reset to 0.

2.25.5 (build 1204) New

  • Bike Birthday 🎂: set an "Owned since" date when adding or editing a bike. On the anniversary your bike card shows a cake, the detail page shows how long you've owned it ("Owned for 2 years, 3 months"), and you get a yearly birthday reminder (toggle in Settings → Notifications → Bike Birthdays).

2.25.4 (build 1203) New

  • Brand autocomplete expansion across all component forms and Add Bike: added ~70 brands — boutique/gravity/gravel bikes, droppers, wheels, tires, drivetrain, brakes (incl. Brembo), cockpit, and e-bike systems.

2.25.2 (build 1201)

  • Fixed the Log Ride Notes field: removed custom scroll logic that was mis-scrolling and adding empty space. The field now behaves exactly like every other form's notes field.

2.25.1 (build 1200)

  • Fixed the top/bottom hairlines on every page: they were the iOS 27 Liquid Glass "scroll edge effect" (only visible on iOS 27). Now hidden app-wide via the shared navigation wrapper.

2.25.0 (build 1199)

  • Reverted all custom nav/tab bar appearance to the clean v2.24.45 baseline — default translucent bars, correct purple tint, no separator lines.

Version 2.24

2.24.89 (build 1188)

  • Log Ride now opens as a full-screen push (with a back button) instead of a slide-up sheet, so typing in Notes/Elevation keeps the field visible above the keyboard.

2.24.81 (build 1180) New

  • Manual Ride: added Elevation section with Ascent and Descent fields (metres). Values are saved, synced via iCloud, and shown in Ride Detail.

2.24.75–2.24.57 (builds 1174–1156)

  • Purple colour sweep: all pickers, sliders, toggles, icons, back buttons, and tab bar elements across the entire app now use the exact TrailRig brand purple. Covers all forms, sheets, and pushed views.

2.24.58 (build 1157) New

  • Garage toolbar layout is now a preference: "Menu" (single wrench) or "Separate buttons" (Swiss Knife, Cost Dashboard, Weight Dashboard each get their own button). Set it in Settings → Preferences → Units & Search.

2.24.56 (build 1155) New

  • Weight Dashboard: see all bikes' weights at a glance — lightest/heaviest summary, comparison bar chart, per-bike breakdown, and top 5 heaviest components across the garage.

2.24.54 (build 1153) New

  • Cassette form: adjusting Smallest or Largest Cog now automatically fills the Range field (e.g. "10-51t"). Cog steppers cover the full real-world range; road cassettes (e.g. 11-28) now fit.

2.24.53 (build 1152) New

  • Frame wheel size now covers the full range: 29", 27.5", 26", 700c, 650b, 24", 20", 16". BMX defaults to 20", road/gravel to 700c.
  • Added a second mullet option: Mix (29F / 26R) for older mixed-wheel builds.

2.24.45 (build 1144)

  • Ride History: elevation totals (ascent ↑ / descent ↓) now appear on their own line, and show thousand separators (12,450 m instead of 12450m).

2.24.44 (build 1143)

  • Fixed: cleaning up a duplicate ride could keep the empty copy and discard the one with your data — the copy with real data is now always kept.
  • Duplicate-ride cleanup is now consistent across devices; older rides no longer get permanently marked "done" with zeros if Health access hadn't been granted yet.

2.24.43 (build 1142) New

  • Older rides now fill in heart rate, speed, elevation, and calories automatically in the background — no need to open each ride one by one.
  • Recovered ride data now syncs to other devices and is included in backups.

2.24.41 (build 1140) New

  • Ride History: long-press any ride to enter selection mode — select individual rides or "Select All", then delete with one tap.

2.24.40 (build 1139)

  • Ride History: duplicate rides (same workout imported twice) are now automatically cleaned up. Bike card totals correctly exclude any rides counted twice.

2.24.39 (build 1138) New

  • Bike card: total elevation (ascent ↑ / descent ↓) now appears below total distance and ride time.
  • Ride History: total distance, ride time, and elevation shown at the top of the list.

2.24.36 (build 1135) New

  • Ride Log: speed, heart rate, elevation, and calories are now saved into the ride record at import time — preserved across backup restores and device transfers.
  • Ride History: tapping a HealthKit ride opens a detail sheet with all stored data.
